# DALIZO 0.1.0-preview.11

## VM settings

- Configure disks, CD/DVD drives, network adapters and USB devices, including SPICE USB redirection. Review hardware edits before saving them with OK.
- Configure the bridge, VLAN, firewall and cable state for each network adapter. Advanced settings include the adapter model, MAC address, rate limit, queues and MTU.
- Change the boot order with arrows beside each device. Other VM options include host autostart, guest agent support and memory ballooning.
- Inspect storage permissions and choose a disk storage when repairing a DALIZO-managed connection.
- Find console explanations behind the help buttons.

## Downloads

For most Windows x64 systems, choose **DALIZO-0.1.0-preview.11-win-x64.zip**, which includes the .NET runtime. Choose **DALIZO-0.1.0-preview.11-win-x64-no-runtime.zip** if the .NET 10 Desktop Runtime for Windows x64 is already installed.

Extract the entire ZIP and start DALIZO.exe. See PREREQUISITES.md for the SPICE and WebView2 requirements. The executable is unsigned.
